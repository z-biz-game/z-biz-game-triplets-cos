「引擎说」那一格写的就是 verify() 的返回：它说还有格没定，画面再好看也没赢。

这三条就是全部规则

  1. 盘面被切成一块块恰好三格的区域——区域是题面给的，粗蓝线就是它们的轮廓。
  2. 每块区域要么三个同号、要么三个全异，不存在「两个一样加一个不一样」。
  3. 跨区域相邻（上下左右）的两格符号必须不同；同区相邻的两格不受这条管。没有别的规则。

出货的每一盘都由引擎实测过：唯一可解（独立穷举计数器在预算内数出 1），而且铅笔在零猜测下推得完（判据见 npm test 与 npm run balance）。
